# 포트폴리오 분석 및 개선 방향 정리

> 작성일: 2026-07-20  
> 목적: 카오스 제로 나이트메어 전투 기획자 지원을 기준으로 현재 포트폴리오 구조와 개선 방향을 정리한다.

---

## 1. 현재 포트폴리오 전체 구조

현재 `D:\BKdesign` 포트폴리오 사이트는 정적 SPA 구조이며, 주요 탭은 다음 순서로 구성되어 있다.

- 자기소개
- 이력서
- 개인 프로젝트
- 참여 프로젝트
- 업무 성과
- 기획 문서

각 탭의 현재 역할은 다음과 같다.

| 탭 | 현재 역할 | 강점 |
|---|---|---|
| 자기소개 | 지원자의 첫인상과 핵심 경력 요약 | 약 5년 경력, 시스템/콘텐츠/BM 기획 경험을 짧게 제시 |
| 이력서 | 경력, 학력, 자격증, 툴 정보 확인 | 경력 2년 이상 요건과 회사/프로젝트 이력 확인 가능 |
| 개인 프로젝트 | Project-A를 통한 전투 기획 역량 제시 | 캐릭터, 몬스터, 데이터, 전투 시스템 설계 역량을 직접 보여줄 수 있음 |
| 참여 프로젝트 | 실제 참여 프로젝트 아카이브 | 라이브/런칭 프로젝트 수와 업무 범위가 넓음 |
| 업무 성과 | 실무 성과 증명 | What/How/Result 구조와 수치 기반 결과가 강함 |
| 기획 문서 | 실무 문서 작성 능력 증명 | 실제 문서 이미지를 오버레이로 확인 가능 |

현재 포트폴리오의 첫인상은 `캐주얼/퍼즐/라이브 서비스 기반의 시스템·콘텐츠·BM 기획자`에 가깝다. 카오스 제로 나이트메어 전투 기획자 지원용으로는 `Project-A`를 통해 전투 기획 역량을 더 선명하게 연결하는 것이 중요하다.

---

## 2. 나한이 기획자 포트폴리오와 비교

참고 사이트: https://hanyi-na.github.io/gamedesign/#recently-played

### 나한이 기획자 포트폴리오의 강점

- 첫 화면에서 주요 담당, 주요 성과, 프로젝트 경험이 빠르게 보인다.
- 프로젝트별로 성과와 기여도가 명확하게 정리되어 있다.
- 문제 해결 사례가 `상황 → 분석 → 행동 → 결과 → 배운점` 흐름으로 읽힌다.
- 플레이로그 섹션을 통해 어떤 게임을 분석하고 플레이하는 기획자인지 드러난다.
- 경력 성과 중심이라 채용 담당자가 짧은 시간 안에 판단하기 쉽다.

### BK 포트폴리오의 강점

- 실제 참여 프로젝트 수와 업무 범위가 넓다.
- `업무 성과` 탭에 What/How/Result 구조가 이미 자리 잡혀 있다.
- `기획 문서` 탭을 통해 문서화 능력을 증명할 수 있다.
- `Project-A`를 통해 전투 시스템, 캐릭터, 몬스터, 데이터 설계를 직접 구현한 사례를 만들 수 있다.

### 현재 차이점

나한이 기획자 포트폴리오는 `경력 성과 증명형`에 가깝고, BK 포트폴리오는 `경력/프로젝트 아카이브형 + 전투 기획 개인 프로젝트 보강형`에 가깝다.

BK 포트폴리오는 경력 기반 신뢰도는 충분하지만, 카오스 제로 나이트메어 공고 기준으로 보면 첫인상에서 아직 `전투 기획자`보다 `캐주얼 시스템/BM/콘텐츠 기획자`로 읽힐 가능성이 있다.

## 3. 추천 정보 구조

사용자가 제안한 탭 순서:

1. 자기소개
2. 이력서
3. 업무 성과
4. 개인 프로젝트
5. 참여 프로젝트
6. 기획 문서

이 순서는 경력직 포트폴리오로 안정적이다.

- `자기소개`: 이 사람이 어떤 기획자인지 첫인상 제시
- `이력서`: 경력 2년 이상 요건과 실제 경력 확인
- `업무 성과`: 결과를 낸 사람인지 증명
- `개인 프로젝트`: 카오스 제로 나이트메어 전투 기획자 공고와 직접 연결되는 준비물 제시
- `참여 프로젝트`: 프로젝트별 상세 경력 확인
- `기획 문서`: 문서화/실무 산출물 확인

단, `개인 프로젝트`가 네 번째에 위치하면 전투 기획 방향성이 늦게 보일 수 있다. 이를 보완하기 위해 자기소개 문구에서 Project-A와 전투 기획 방향성을 한 번 예고하는 것이 좋다.

예시 방향:

> 약 5년간 시스템·콘텐츠·BM 기획을 중심으로 글로벌 게임 서비스에 참여해왔으며, 현재는 전투 시스템·캐릭터·몬스터 설계를 직접 구현한 개인 프로젝트를 통해 전투 기획 역량을 확장하고 있습니다.

## 4. Project-A 개인 프로젝트 탭 개선 방향

Project-A는 현재 카오스 제로 나이트메어 전투 기획자 공고와 가장 직접적으로 연결되는 탭이다. 앞으로는 단순 소개보다 `실제 전투 기획 실무를 직접 재현한 제작형 포트폴리오`로 강화하는 것이 좋다.

우선 강화할 항목:

- 캐릭터 기획: 츠키의 자세 전환 구조, 카드별 역할, 키워드 설계 의도 보강
- 몬스터 기획: 몬스터별 역할, 행동 패턴, 전투 퍼즐에서의 압박 방식 정리
- 데이터 작업: 카드/효과/조건/자세 데이터 분리 구조와 유지보수 장점 시각화
- 전투 시스템: 타겟팅, 턴 진행, 다단히트, RP 스킬, 사망 처리 등 구현된 루프 설명
- 문제 해결 사례: 카드 설명과 실제 효과 불일치, 전투 판독성, 몬스터 사망 처리 등 개선 사례 작성

권장 서술 구조:

`기획 의도 → 설계 방식 → 구현 결과 → 개선 예정`

## 5. 츠키 애니메이션 GIF/WebP 후보

현재 포트폴리오 저장소에는 츠키 애니메이션 GIF가 없다. 대신 `D:\Project_Sceret` 게임 프로젝트에는 GIF/WebP로 만들 수 있는 스프라이트시트와 VFX 자산이 있다.

확인된 원본 후보:

- `project-a/assets/characters/spritesheets/tsuki_spritesheet.png`
- `project-a/assets/characters/spritesheets/tsuki_five_slash_spritesheet.png`
- `project-a/assets/vfx/fx_tsuki_five_slash.png`
- `project-a/assets/vfx/moon_slash_sheet.png`
- `project-a/scenes/vfx/fx_sonic_boom.tscn`

제작 후보 5종:

| 후보 | 난이도 | 메모 |
|---|---|---|
| 츠키 Idle 모션 | 낮음 | 기존 `Idle` 애니메이션 프레임 기반으로 제작 가능 |
| 츠키 Attack 모션 | 낮음 | 기존 `Attack` 애니메이션 프레임 기반으로 제작 가능 |
| 츠키 Sonic Boom 이동 후 Attack | 중간 | 이동, 소닉붐, 공격을 합성해야 하므로 연출 조정 필요 |
| 츠키 Dead 모션 | 낮음 | 기존 `Dead` 애니메이션 프레임 기반으로 제작 가능 |
| Five Slash + Moon Slash VFX 합성 | 중간~높음 | 본체 모션, Five Slash VFX, Moon Slash VFX의 위치/타이밍 조정 필요 |

포트폴리오 웹에서는 GIF보다 animated WebP가 용량과 품질 면에서 더 유리할 수 있다. 다만 호환성과 삽입 편의성은 GIF가 가장 단순하다.

추천 제작 순서:

1. Idle / Attack / Dead 기본 모션 제작
2. Five Slash 단독 또는 Five Slash + VFX 제작
3. Sonic Boom 이동 후 Attack, Five Slash + Moon Slash VFX 합성 연출 다듬기
